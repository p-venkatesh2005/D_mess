HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

Every time a student:
  ✓ Loads dashboard
  ✓ Books a meal
  ✓ Scans a QR code
  ✓ Marks attendance
  ✓ Accesses any subscription feature

The system:
  1. Calls: validate_and_sync_subscription(student_id)
  2. Compares: subscription_end date with TODAY
  3. Never trusts stored status alone
  4. Auto-corrects if status is wrong
  5. Calculates warning level (7, 3, 1, or None)
  6. Returns comprehensive state

VALIDATION CHAIN
═══════════════════════════════════════════════════════════════════════════

Before Meal Booking:
  1. Check: is_valid = can_book_meal(student_id)
  2. If False: Flash error message → Redirect
  3. If True: Allow booking to proceed

Before QR Scan:
  1. Check: is_valid = can_scan_qr(student_id)
  2. If False: Flash error message → Redirect
  3. If True: Process QR scan

Before Attendance:
  1. Check: is_valid = can_mark_attendance(student_id)
  2. If False: Flash error message → Redirect
  3. If True: Mark attendance

General Feature Access:
  1. Check: is_valid = can_access_mess_features(student_id)
  2. If False: Show warning → Redirect to subscribe
  3. If True: Allow feature access


SUBSCRIPTION STATE OBJECT
═══════════════════════════════════════════════════════════════════════════

sub_state = get_subscription_state(student_id)

Fields:
  sub_state['is_valid']          → True/False (can use services?)
  sub_state['status']            → 'active' / 'inactive' / 'expired'
  sub_state['days_remaining']    → Days left (negative if expired)
  sub_state['expiry_date']       → Subscription end date
  sub_state['warning_level']     → 7 / 3 / 1 / None
  sub_state['needs_renewal']     → True if expired
  sub_state['corrected']         → True if status was auto-fixed
  sub_state['messages']          → List of alert messages


RENEWAL PROCESS
═══════════════════════════════════════════════════════════════════════════

To renew subscription:
  success, msg = process_subscription_renewal(student_id, months=1)

  ✅ If expired: Starts fresh from today
  ✅ If active: Extends from current end date
  ✅ Auto-handles month overflow (Jan 31 + 1 month = Feb 28)
  ✅ Auto-handles year overflow (Dec + 1 month = Jan next year)
  ✅ Updates student record
  ✅ Creates Subscription tracking record
  ✅ Returns success message with new expiry date
