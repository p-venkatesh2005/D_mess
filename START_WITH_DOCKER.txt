STEP-BY-STEP INSTALLATION
================================================================================

STEP 1: INSTALL DOCKER DESKTOP
────────────────────────────────────────────────────────────────────────────

1. Open your browser and go to:
   https://www.docker.com/products/docker-desktop/

2. Click "Download for Windows"
   (File size: ~500MB, download time: 2-5 minutes)

3. Run the downloaded installer: "Docker Desktop Installer.exe"

4. During installation:
   ✓ Accept the license agreement
   ✓ Keep default settings (Enable WSL 2 if prompted)
   ✓ Click "Install"
   
5. When prompted, restart your computer

6. After restart, open "Docker Desktop" from Start Menu

7. Wait for Docker to start (green icon in system tray)
   First start takes 2-3 minutes

8. You'll see "Docker Desktop is running" message

STEP 2: VERIFY DOCKER IS WORKING
────────────────────────────────────────────────────────────────────────────

1. Open PowerShell (Windows key + X, then select "PowerShell")

2. Type these commands to verify:

   docker --version
   docker-compose --version

3. You should see version numbers like:
   Docker version 24.x.x
   Docker Compose version 2.x.x

✅ If you see version numbers, Docker is ready!
❌ If you see "command not found", restart PowerShell and try again

STEP 3: START DWARAKA MESS SYSTEM
────────────────────────────────────────────────────────────────────────────

Option A: Using Quick Start Script (Easiest)
   1. Open PowerShell
   2. Navigate to project:
      cd c:\Users\venka\Downloads\D_mess-main\D_mess-main
   3. Run quick start:
      .\scripts\docker-quick-start.bat
   4. Wait 3-5 minutes for first-time setup
   5. Open browser: http://localhost:5000

Option B: Manual Commands
   1. Open PowerShell
   2. Navigate to project:
      cd c:\Users\venka\Downloads\D_mess-main\D_mess-main
   3. Copy environment file:
      copy .env.example .env
   4. Start services:
      docker-compose up -d
   5. Wait 15 seconds:
      timeout /t 15
   6. Initialize database:
      docker exec -it dwaraka_mess_app python init_db.py
   7. Open browser: http://localhost:5000

================================================================================
WHAT DOCKER COMPOSE DOES
================================================================================

When you run "docker-compose up -d":

1. Downloads PostgreSQL 16 Alpine image (~80MB)
2. Downloads Python 3.11 base image (~150MB)
3. Builds your Flask application container
4. Creates PostgreSQL database container
5. Creates persistent data volume (your data is safe even if you restart)
6. Starts both containers
7. Connects them via internal network
8. Exposes ports:
   - 5432 for PostgreSQL (database)
   - 5000 for Flask app (web interface)

Total download: ~250MB (first time only)
Time: 3-5 minutes (first time), 10 seconds (subsequent starts)

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Docker Desktop won't start
SOLUTION: 
   - Enable virtualization in BIOS/UEFI
   - Run: wsl --install
   - Restart computer

PROBLEM: "Port 5000 is already in use"
SOLUTION:
   - Edit docker-compose.yml
   - Change line: "5000:5000" to "5001:5000"
   - Access at: http://localhost:5001

PROBLEM: Container keeps restarting
SOLUTION:
   - Check logs: docker-compose logs app
   - Check logs: docker-compose logs postgres
   - Rebuild: docker-compose down -v && docker-compose up -d --build

PROBLEM: Can't access http://localhost:5000
SOLUTION:
   - Check if containers are running: docker-compose ps
   - Both should show "Up"
   - Check app logs: docker-compose logs app
   - Try: http://127.0.0.1:5000

PROBLEM: Database initialization failed
SOLUTION:
   - Wait 30 seconds after starting containers
   - Run again: docker exec -it dwaraka_mess_app python init_db.py
