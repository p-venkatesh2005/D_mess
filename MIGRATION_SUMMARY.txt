   DB_PASSWORD=<secure-password>
   DB_HOST=<prod-host>
   DB_PORT=5432
   DB_NAME=dwaraka_mess_prod

   DB_POOL_RECYCLE=1800
   DB_MAX_OVERFLOW=40

Generate SECRET_KEY:
   python -c "import secrets; print(secrets.token_hex(32))"

================================================================================
TROUBLESHOOTING
================================================================================

Connection Refused:
   - Check if PostgreSQL is running: docker-compose ps
   - Check logs: docker-compose logs postgres
   - Restart: docker-compose restart postgres

Pool Overflow:
   - Increase pool size in .env
   - DB_POOL_SIZE=30, DB_MAX_OVERFLOW=60

Slow Queries:
   - Indexes already created
   - Check EXPLAIN ANALYZE
   - Enable query logging in config.py

Database Not Starting:
   - Check logs: docker-compose logs postgres
   - Rebuild: docker-compose down -v && docker-compose up --build -d

UNIQUE Constraint Error:
   - Fixed: Email field is now optional with duplicate checking
