## 🚨 IF SOMETHING GOES WRONG

**App won't load:**
- Wait 60 seconds (spin-up time)
- Check Render dashboard for errors

**Login fails:**
- Double-check credentials
- Ensure fresh DB setup was run

**Attendance chart empty:**
- Fresh DB has sample data
- Click any bar to test

**Payment screenshot won't show:**
- Check Cloudinary credentials in Render
- Verify CLOUDINARY_ENABLED=true
